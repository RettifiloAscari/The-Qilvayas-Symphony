# QS Style Template (encoded)

Base64-encoded Word template for the document pipeline. Project knowledge
converts .docx uploads to plain text, which destroys the binary, so the
template ships encoded here instead. `transplant.py` decodes this file
automatically — no manual step required.

Embedded fonts are stripped to keep this file small; install Alegreya and
Alegreya Sans locally (free, Google Fonts) for correct on-screen rendering.
